Confidentialité

Chaque texte existe en français et en anglais : colle la langue de ton choix (l’anglais accélère parfois l’examen).

Code distant

Non, je n’utilise pas de code distant.

Tout le code est dans le package. Le serveur ne renvoie que des données chiffrées, jamais de code.

Consommation des données : quelles données collectez-vous ?

  • Informations permettant d’identifier personnellement l’utilisateur Les prénoms des membres du foyer, saisis par l’utilisateur, sont envoyés (chiffrés de bout en bout) au serveur de synchro.
  • Information sur la santé
  • Informations financières et de paiement Aucun montant, moyen de paiement ni contenu d’achat n’est lu : seulement le numéro de commande (voir « Contenu du site Web »).
  • Informations d’authentification Aucun identifiant de l’utilisateur. Le code d’invitation est une clé générée par l’extension, pas un identifiant de compte.
  • Communications personnelles
  • Localisation Les adresses IP ne sont ni journalisées ni conservées.
  • Historique Web Aucune liste des pages visitées n’est enregistrée.
  • Activité de l’utilisateur
  • Contenu du site Web Les numéros de commande lus sur les pages Amazon ; ceux des commandes cachées sont envoyés chiffrés au serveur.

Coche aussi les trois certifications :

  • Je ne vends ni ne transfère les données des utilisateurs à des tiers en dehors des cas d’utilisation approuvés
  • Je n’utilise ni ne transfère les données des utilisateurs à des fins sans rapport avec la fonctionnalité de base de mon article
  • Je n’utilise ni ne transfère les données des utilisateurs pour déterminer leur solvabilité ou à des fins de prêt
